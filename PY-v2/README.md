# PY-v2 (Enhanced Desktop App)

Desktop calculator built with `PyQt6`, featuring scientific functions.

## Features

- **Scientific Mode**: sin, cos, tan, log, etc.
- **Theme**: Catppuccin Mocha colors.
- **Logic**: Handles trig and log functions.

## 🚀 How to Run

1. **Ensure you have Python installed**.

2. **Navigate to the directory**:

   ```bash
   cd PY-v2
   ```

3. **Install Dependencies**:

   ```bash
   pip install PyQt6
   ```

4. **Run the App**:
   ```bash
   python app.py
   ```
