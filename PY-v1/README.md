## Features

- Basic math logic
- Error handling

## 🚀 How to Run

1. **Ensure you have Python installed**.

2. **Navigate to the directory**:

   ```bash
   cd PY-v1
   ```

3. **Run the App**:
   ```bash
   python app.py
   ```
