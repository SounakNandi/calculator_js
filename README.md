# Calculator-Suite

A collection of calculator apps built with JavaScript and Python. This project compares different ways to build a calculator across web and desktop.

## 📁 Project Structure

Check each folder for more info:

1. **[JS-v1](./JS-v1)** (Web Classic): Simple web calculator.
2. **[JS-v2](./JS-v2)** (Web Enhanced): Web calculator with scientific functions and dark mode.
3. **[PY-v1](./PY-v1)** (Classic Desktop App): Basic Python calculator made with Tkinter.
4. **[PY-v2](./PY-v2)** (Enhanced Desktop App): Desktop calculator built with PyQt6.

## 🛠️ Tech Used

- **Web**: HTML, CSS, JavaScript
- **Desktop**: Python (Tkinter, PyQt6)
